# Flashlight Mod

Простий навчальний мод для Minecraft 1.21.1 (Fabric).

Дає предмет **Flashlight** (Ліхтарик). ПКМ вмикає/вимикає його —
поки увімкнено, мод ставить невидимий блок світла (`minecraft:light`)
трохи попереду гравця і щотіку пересуває його за поглядом.

Детальний розбір коду — у відповіді Клода, де цей проєкт створювався.

## Як зібрати і запустити

1. Відкрий цю папку в IntelliJ IDEA (File → Open → обери папку flashlightmod).
2. Почекай, поки Gradle сам завантажить усе потрібне (перший раз — довго, якісний інтернет обов'язковий).
3. У панелі Gradle (справа) відкрий: flashlightmod → Tasks → fabric → runClient.
4. Після запуску створи світ і візьми ліхтарик через творчий інвентар
   (вкладка Tools & Utilities) або команду:
   `/give @s flashlightmod:flashlight`
